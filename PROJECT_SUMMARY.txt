Project Title: CyberSafe - Cybersecurity Awareness & Quiz App

One-line proposal:
An offline React Native app that teaches students cybersecurity basics through searchable lessons, category filters, and interactive quizzes.

Technologies: React Native, Expo, Expo Router, JavaScript (JSX), JSON, Ionicons.
Screens: Home, Topics, Topic Details, Quiz, Quiz Results.
Data: 8 sample learning topics and 24 sample quiz questions stored in local JSON.
No backend, database server or internet API is used.

REMINDER: Use a unique registered title and customize the dataset for your individual submission.
