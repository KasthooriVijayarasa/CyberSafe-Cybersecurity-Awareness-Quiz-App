# 🛡️ CyberSafe – Cybersecurity Awareness & Quiz App

## Project Overview

CyberSafe is a mobile application designed to improve cybersecurity awareness through educational content and interactive quizzes. The application helps users understand common cyber threats, learn safe online practices, and evaluate their cybersecurity knowledge.

The application is developed using React Native and Expo as part of the IT3133 Mobile Computing ICA 03 assignment.

## Features

- User-friendly home screen
- Cybersecurity awareness topics
- Topic search and category filtering
- Detailed explanations of cybersecurity concepts
- Interactive multiple-choice quizzes
- Automatic score calculation
- Quiz results and performance feedback
- Offline access to educational content
- Bottom tab navigation

## Technologies Used

- React Native
- Expo
- Expo Router
- JavaScript
- JSON
- Git and GitHub

## Installation and Setup

### Prerequisites

- Node.js
- npm
- Expo Go application on a mobile device

### Installation

1. Clone the repository:

```bash
git clone https://github.com/KasthooriVijayarasa/CyberSafe-Cybersecurity-Awareness-Quiz-App
```

2. Navigate to the project directory.

3. Install dependencies:

```bash
npm install
```

4. Start the application:

```bash
npx expo start
```

5. Scan the QR code using Expo Go to open the application on your mobile device.

## How to Use

1. Open CyberSafe.
2. Browse the available cybersecurity topics.
3. Select a topic to read its detailed explanation.
4. Navigate to the Quiz screen.
5. Answer the multiple-choice questions.
6. View your final score and performance feedback.
